# UNIX V6 filesystem (external plugin, read-only)

`NyaFsAncientFs` reads the PDP-11 UNIX V6 filesystem used on RX50/RD52 media:

```text
load ra1boot.rx50
ls /
export out/
```

The reader is selected by the V6 superblock/inode layout; `.rx50`/`.v6`
extensions are recognised as hints.

## Reader support

- 512-byte blocks; superblock at block 1;
- 32-byte V6 inodes starting at block 2 (`s_isize` controls the inode area);
- 16-byte directory entries;
- direct blocks and the V6 `ILARG` single-indirect large-file format;
- files, directories, character and block device nodes with uid/gid/mode.

## Limitations

- read-only: no writer;
- V6 has no symlinks, and timestamps are not exposed by the reader interface;
- only the first 128 indirect entries (`ILARG`) are used, matching V6's
  64 KiB large-file limit;
- free-list consistency/fsck checks are not performed.

## Verification

- real `ra1boot.rx50` from hamartun.priv.no (409600 bytes) loads as V6 and
  lists `bin`, `dev`, `etc`, `lib`, `mnt`, `tmp`, `usr`, `unix`, `unix.rd52`;
- `V6FsTests` checks tree traversal, `/bin/ls`, `/unix` and `/etc/passwd`
  hashes, plus pipeline loading.
