# UDF

`NyaFs` can read UDF images and write basic UDF images (ECMA-167/OSTA).

## Commands

UDF is auto-detected by the `BEA01` volume recognition sequence:

```text
load image.udf
export out/
```

Write a basic UDF image:

```text
store out.udf ramfs udf
```

Enable VAT output before `store`:

```text
set ramfs udf.vat true
```

Or enable a sparable partition:

```text
set ramfs udf.sparable true
```

## Supported layout

- UDF revisions 1.02/2.01/2.50/2.60 images with 2048-byte (and common alternate)
  logical blocks.
- Anchor, main volume descriptor sequence, logical/partition descriptors.
- File Set Descriptor and root ICB.
- File Entry and Extended File Entry, short/long/extended allocation
  descriptors and inline (`AD_IN_ICB`) data.
- Directories (FID), files, symlinks, uid/gid and permissions.
- Both absolute and partitioned ICB locations.
- Partition-map resolution for type1, virtual (VAT) and sparable partitions.
- VAT images, including the hidden VAT file and virtual-to-physical mapping.
- Sparing tables on read; sparable images with no remapped blocks are accepted.
- Multi-partition type1 references in ICBs.

## Writer limits

- 2048-byte blocks, UDF 2.01-compatible descriptors;
- short allocation descriptors, one ICB per node;
- basic FE/EFE/FID layouts; no UDF extended attributes;
- optional VAT output with an identity VAT table (mount-validated);
- optional sparable output with an empty sparing table (mount-validated);
- no metadata-partition output yet.

## Not supported yet

- UDF extended attributes and UDF-specific metadata beyond the generic model;
- metadata partitions on write;
- real remapping entries in a sparing table on write.

## Verification

- Built populated images with `mkudffs` 2.3 and tested `load`/`export` against
  files, nested directories and symlinks.
- `UdfTests` covers the reader against a fixture generated by `mkudffs`, VAT and
  sparable images, and writer round-trips.
- VAT writer images mount read-only under Linux UDF and expose files, nested
  directories and symlinks correctly.
